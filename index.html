04

小项目：猜数字游戏

学完前 6 节，你已经会写一个真正能玩的游戏了。电脑随机想一个 1–100 的数字，你来猜，它会提示大了还是小了。

1随机出题

用 random.randint(1, 100) 让电脑想一个数字，存进变量。

2循环猜

用 while 循环反复让玩家输入，直到猜中为止。

3判断大小

用 if / elif / else 比较，给出「太大了」「太小了」的提示。

4计次收尾

数一数猜了几次，猜中后打印成绩，猜得越少越厉害。

guess.py — 复制到电脑上的 Python 里就能玩
import random

answer = random.randint(1, 100)
count = 0

print("我想了一个 1 到 100 的数字，来猜猜看！")

while True:
    guess = int(input("你猜的是："))
    count = count + 1
    if guess > answer:
        print("太大了，再小一点")
    elif guess < answer:
        print("太小了，再大一点")
    else:
        print(f"猜对啦！你一共猜了 {count} 次")
        break
进阶挑战：给自己加难度——限制最多猜 7 次，猜满还没中就公布答案；或者把范围改成 1–1000，看看要猜多少次。
