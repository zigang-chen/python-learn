# Python 学习小程序

面向青少年的 Python 入门学习小工具，单文件网页版，打开 `index.html` 即用。

## 内容

- 6 节短课：print、变量与数字、字符串、if 判断、循环、列表与函数
- 每节带讲解、例题和运行结果，学完可标记完成，自动跳到下一节没学的课
- 迷你 Python 练手台：支持变量、print、四则运算、字符串、f-string，写错了给中文提示
- 10 道随堂测验：即时判分，带解析
- 小项目：猜数字游戏，分 4 步讲解，附完整代码

## 使用

直接用浏览器打开 `index.html` 即可，无需安装，不依赖后端。

## 说明

学习进度只在当次打开内记录，刷新后重置。
